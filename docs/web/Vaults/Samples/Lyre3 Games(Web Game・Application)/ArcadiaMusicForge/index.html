📘 Arcadia Music Forge 機能・操作ガイド

確認日：2026年9月9日
確認対象：ローカル main、コミット ca565f4 の index.html、README、統合資料、回帰テスト。GitHub公開版の反映状態は別途確認が必要です。

🎵 1. どんなツールか

Arcadia Music Forgeは、ブラウザ上でゲームBGMのたたき台を生成し、音符・音色・曲構成を編集して、プロジェクト、MIDI、WAVとして保存するツールです。単一HTMLに画面と生成・音声処理を収めています。
中心となる単位は「4小節のパターン」と「48小節のアレンジメント」です。音楽制作ソフトのように無制限のトラックを追加する構成ではなく、7パートを組み合わせて曲を作ります。
|トラック|主な役割|
|---|---|
|メロディー|主旋律|
|カウンターメロディー|主旋律に対する補助旋律|
|ストリングス|和音・持続する伴奏|
|ブラス|アクセントや伴奏|
|アルペジオ|和音を分散した動き|
|ベース|低音の支え|
|ドラム|リズム|
実機ファミコン／スーファミの音源エミュレーターではありません。7トラックは同時発音数の上限ではなく、1トラックに和音を置けば複数の音が同時に鳴ります。

🚀 2. 最初の曲を作る手順

1. 新規プロジェクトまたは曲ライブラリで曲を用意します。
2. ROOTとSCALEを設定します。
3. GENERATORでジャンル、STYLE、進行、進行モードを選びます。選んだコード進行を使う場合は「指定進行」を選びます。
4. SEEDを指定します。同じ条件で比較するときは「毎回変更」を外します。
5. 「自動生成」でパターンと48小節の配置を生成します。BPMや音色も更新されます。
6. 再生して、アレンジメントの音量・ミュート・ソロを調整します。
7. ピアノロールで音符を編集し、必要に応じてSOUND DESIGNやPCM SAMPLERを使います。
8. まずプロジェクトを保存し、その後にMIDIやWAVを書き出します。
自動生成は既存の生成対象パターンや配置を更新します。大切な編集は先に保存、または曲を複製してください。

🧭 3. 画面ごとの機能

📚 曲ライブラリ

複数曲をプロジェクト内で管理します。曲名変更、追加、複製、削除、曲の切り替えに対応します。ブラウザ内の自動保存に加え、プロジェクトファイルとして保存できます。曲を切り替えるとUndo履歴はクリアされます。

⚙️ GENERATOR

音楽ジャンルと情景・ムードを組み合わせて作曲します。例えば「ピアノ × 雨の日の部屋」「シンセウェーブ × 夜の街」「オーケストラ × 旅立ち」。Geminiの接続は不要です。
|設定|現在の実装での働き|
|---|---|
|情景・ムード|テンポ、自動選択する旋律・リズム・進行の候補、伴奏の音数、強弱やセクションごとの厚み|
|音楽ジャンル（旧STYLE）|音色、テンポ補正、音域、音数、アルペジオの刻み、ベース・ドラムの傾向|
|進行|「指定進行」時にGENERATORの選択を使用。解釈可能な4コードの場合に適用|
|指定進行|選択した進行を基本に生成|
|おまかせ|ジャンルタグに合うDegree進行候補を選択|
|展開あり|BやCLIMAXの進行を変化させる|
|コード少なめ|和音の切り替えを減らす|
|SEED|生成用乱数の起点。同じ条件での再現・比較に使用|
情景は朝、夜の街、雨の日の部屋、海辺、旅立ち、祝祭、追憶、ミステリー、星空、決意の10種類。従来のゲーム向け13種類も選べます。主旋律とリズムを自動選択にすると情景を参考に選びます。ROOT／SCALEは現在の指定を使用します。明るさを変えたい場合はSCALEも調整してください。
STYLEはSNES風、NES風、オーケストラ風、FM音源、ピアノ、アンビエント、ロック、ファンク、ジャズ、ボサノバ、ハウス、テクノ、ドラムンベース、シンセウェーブ、和風、民族音楽風の16種類です。機種別のチャンネル制限はありません。
進行一覧には基本進行と、カノン、小室、王道、織田哲郎、循環、ポップパンク、アンダルシア風、冒険系、切ないゲーム系、ボス戦系、ホラー系、SF系などがあります。名称はアプリ内ラベルであり、音楽理論上の名称の正確さを保証するものではありません。

🎼 THEORY ASSIST

ROOT／SCALEから和音を計算し、手動で音楽を組み立てる補助機能です。
- 12のROOT、17のスケール、Triad／7th切り替え。
- Degree進行、配置先小節の指定、コード配置。
- メロディー、ベース、アルペジオの個別生成。
- 和音試聴、コード／スケール逆引き、進行履歴の保存・復元。
- ピアノロールのScale Tone／Chord Tone表示。
- 滑らかな和音配置：手動配置時のストリングスのボイシングを調整。初期OFF。
- フレーズ補助：生成後の主旋律を4小節の主題・応答・変化・結びとして整える。初期OFF。
コード配置は現在パターンのストリングス・ブラス・ベースを置き換えます。個別生成は対象パートを更新します。ROOT変更は既存の非ドラム音符も移調します。SCALEや進行の変更だけで既存音符全体を作り直すわけではありません。
逆引きは音の集合に合う候補を探す機能です。曲の調やコードを一意に断定するものではありません。

🧩 アレンジメント

48小節を4小節×12ブロックで扱い、各トラックにパターンを配置します。クリックでパターン切り替え、右クリックでOFF、ドラッグで移動・コピーする処理があります。標準構成の配置、配置クリア、トラックごとの音量・ミュート・ソロに対応します。
スマホ幅では横スクロール用の幅指定があります。ただし、タッチ端末でのドラッグや実際のスクロール操作は端末ごとの確認が必要です。

🎹 PIANO ROLL

4小節・64ステップのグリッドを使い、音符を追加・選択・編集します。表示音域はE4～E6です。音価、ベロシティ、クオンタイズ、半音移調、ヒューマナイズ、音符コピー／貼り付け／削除、パターンの追加・複製・改名・削除を備えます。
INTRO、A、B、BREAK、CLIMAX、TURNなどのパターンを切り替えて編集し、アレンジメントへ配置します。Undo履歴は最大30件です。すべての操作にUndoが付くとは限りません。

🎛️ SOUND DESIGN

選択トラックの音色・エンベロープ・フィルター・パン・LFOなどを調整し、音色プリセットの保存・読込・試聴を行います。
「FX全オフ」はライブ再生のリバーブとディレイをバイパスします。フィルター、エンベロープ、LFOなど音作り全体を無効にするスイッチではありません。現在はスマホ判定時に初期ON、PCでは初期OFFです。

🔊 PCM SAMPLER

音声ファイルをトラック用またはドラム用サンプルとして読み込みます。基準音、音量、ループ開始／終了、ワンショット、フェードを調整できます。波形表示、トリミング、ノーマライズ、逆再生を備えます。音声形式の対応はブラウザのデコード能力に依存します。

✨ CHROME GEMINI（オプション）

文章で曲の設計図や音符生成を依頼する補助機能です。設計図は保存されますが、それだけで48小節の曲へ自動配置される機能ではありません。作曲結果は別の「結果を現在パターンへ反映」で適用します。
Chrome内蔵LanguageModel APIとモデルの準備が必要です。この環境ではダウンロード／セッション準備が完了しない事象があり、実用動作は未確認です。通常のGENERATORはGeminiなしで利用できます。

▶️ 4. 再生と保存

|項目|内容|
|---|---|
|軽量再生|従来のタイマー方式。安定再生とは別方式です|
|安定再生（初期値）|AudioContextの時刻で先行予約する方式|
|先読み|50／100／200／400／600／800／1,000ms。初期200ms。安定再生に適用|
|LOOP|開始・終了小節を指定|
|MASTER|全体の再生音量|
|プロジェクト保存／読込|曲・音符・音色・配置・サンプルデータなどを保持するための形式|
|MIDI保存|48小節の音符、ベロシティ、テンポをファイル化。アプリの音色・FXそのものは保存しない|
|MIDI読込|MIDI解析・取り込み処理あり。外部ソフトの全情報を完全再現するものではない|
|WAV|44.1kHz、ステレオ、16bit PCMへオフライン音声化|
WAVはライブ再生とは別処理です。現在のWAV処理にはライブ用リバーブ・ディレイ接続がなく、再生音と完全一致しません。

💡 5. 活用に向く場面

ゲームBGMのアイデア出し、短いフレーズの比較、コードとメロディーの学習、音色・サンプルの試作、DAWへ渡すMIDI素材作りに向きます。実機音源の厳密な再現や、長時間・高負荷のライブ運用については追加の実装・検証が必要です。
