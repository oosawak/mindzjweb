# Acerca de MindZJWeb

MindZJWeb es una versión web de [MindZJ](https://zenn.dev/superjohn/articles/752679bdcdc37e), adaptada para gestionar documentos Markdown desde el navegador. Organiza notas y recursos en carpetas y consúltalos o edítalos desde el navegador.

## Funciones principales

- Leer y editar notas Markdown o ver su código fuente. Pulsa Guardar después de editar.
- Añadir y previsualizar imágenes, PDF, audio, vídeo, HTML y recursos 3D. La vista previa depende del tipo de archivo.
- Abrir en la aplicación las páginas web registradas en archivos `.url`. Haz Ctrl/Cmd-clic en un enlace para abrirlo en un navegador externo.
- Crear informes diarios y actas de reuniones desde el calendario.
- Editar imágenes con PhotoCraft y PDF con PrintCraft. Los archivos editados se pueden guardar en el Vault.
- Administrar notas, archivos adjuntos y carpetas desde la barra lateral.

## Guardado en esta demostración

En la demostración de GitHub Pages, las notas modificadas y los archivos añadidos se guardan en el navegador actual. No se sincronizan automáticamente con otros navegadores o dispositivos. La versión de servidor guarda los archivos en un Vault del servidor.

Para las organizaciones que necesiten controlar el acceso, se podrá considerar la autenticación mediante Google Groups según sus necesidades.

## Primeros pasos

Selecciona una nota en la lista de la izquierda para leerla. Elige Editar para cambiarla y pulsa Guardar. Usa el menú de la barra lateral para añadir archivos y carpetas.
