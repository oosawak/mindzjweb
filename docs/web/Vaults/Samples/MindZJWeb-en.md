# About MindZJWeb

MindZJWeb is a web version of [MindZJ](https://zenn.dev/superjohn/articles/752679bdcdc37e), adapted to manage Markdown documents in a browser. Browse and edit notes and resources organized in folders.

## Main features

- Read and edit Markdown notes, or view their source. Save edits with the Save button.
- Add and preview images, PDFs, audio, video, HTML, and 3D assets. Preview support depends on the file type.
- Open web pages registered in `.url` files inside the app. Ctrl/Cmd-click a link to open it in an external browser.
- Create daily reports and meeting minutes from the calendar.
- Edit images with PhotoCraft and PDFs with PrintCraft. Edited files can be saved back to the Vault.
- Manage notes, attachments, and folders from the sidebar.

## Saving in this demo

In the GitHub Pages demo, edited notes and added files are saved in the current browser. They do not sync automatically across browsers or devices. In the server version, files are stored in a Vault on the server.

For organizations that need access control, Google Group authentication may be added in the future based on user needs.

## Get started

Select a note in the left sidebar to read it. Choose Edit to make changes, then press Save. Add files and folders from the sidebar menu.

## Work in progress
