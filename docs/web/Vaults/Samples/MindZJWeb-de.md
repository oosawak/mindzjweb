# Über MindZJWeb

MindZJWeb ist eine Webversion von [MindZJ](https://zenn.dev/superjohn/articles/752679bdcdc37e), die für die Verwaltung von Markdown-Dokumenten im Browser angepasst wurde. Notizen und Ressourcen lassen sich in Ordnern organisieren und im Browser ansehen und bearbeiten.

## Hauptfunktionen

- Markdown-Notizen lesen und bearbeiten oder den Quelltext anzeigen. Änderungen werden über die Schaltfläche Speichern gesichert.
- Bilder, PDFs, Audio, Videos, HTML und 3D-Dateien hinzufügen und in der Vorschau ansehen. Die Vorschau hängt vom Dateityp ab.
- In `.url`-Dateien eingetragene Webseiten in der App öffnen. Mit Strg-/Cmd-Klick auf einen Link wird er im externen Browser geöffnet.
- Tagesberichte und Besprechungsprotokolle über den Kalender erstellen.
- Bilder mit PhotoCraft und PDFs mit PrintCraft bearbeiten. Bearbeitete Dateien können im Vault gespeichert werden.
- Notizen, Anhänge und Ordner in der Seitenleiste verwalten.

## Speichern in dieser Demo

In der GitHub-Pages-Demo werden geänderte Notizen und hinzugefügte Dateien im aktuellen Browser gespeichert. Eine automatische Synchronisierung zwischen Browsern oder Geräten gibt es nicht. Die Serverversion speichert Dateien in einem Vault auf dem Server.

Für Organisationen mit Zugriffsbeschränkungen kann künftig je nach Bedarf eine Anmeldung über Google Groups erwogen werden.

## Erste Schritte

Wählen Sie links eine Notiz zum Lesen aus. Wählen Sie Bearbeiten, nehmen Sie Änderungen vor und klicken Sie auf Speichern. Über das Menü der Seitenleiste können Sie Dateien und Ordner hinzufügen.
