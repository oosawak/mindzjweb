# 关于 MindZJWeb

MindZJWeb 是 [MindZJ](https://zenn.dev/superjohn/articles/752679bdcdc37e) 的 Web 版本，经过调整后可在浏览器中管理 Markdown 文档。你可以通过文件夹整理笔记和资源，并在浏览器中查看和编辑。

## 主要功能

- 阅读、编辑 Markdown 笔记或查看源代码。编辑后请点击“保存”。
- 添加并预览图片、PDF、音频、视频、HTML 和 3D 资源。预览能力取决于文件类型。
- 在应用内打开 `.url` 文件中登记的网页。按住 Ctrl/Cmd 点击链接可在外部浏览器中打开。
- 通过日历创建日报和会议纪要。
- 使用 PhotoCraft 编辑图片，使用 PrintCraft 编辑 PDF。编辑后的文件可以保存回 Vault。
- 在侧边栏管理笔记、附件和文件夹。

## 此演示中的保存方式

在 GitHub Pages 演示版中，修改的笔记和添加的文件保存在当前浏览器中，不会自动同步到其他浏览器或设备。服务器版会将文件保存在服务器上的 Vault 中。

如果组织需要访问控制，未来可根据需求考虑加入 Google Group 身份验证。

## 开始使用

在左侧列表中选择笔记即可阅读。选择“编辑”进行修改，然后点击“保存”。可通过侧边栏菜单添加文件和文件夹。

## 开发中的功能

- Google Group 用户认证
- 连接 T2Code（计划仅在连接 Local AI Server 时提供）
- 音乐文件 Stem 分离及 MIDI 转换（计划仅在连接 Local AI Server 时提供）

这些功能仍在规划或开发中，目前尚不可用。
