- BGM・効果音・ボイスは ElevenLabs で生成します(`tools/elevenlabs/`)。
- 公開・配布・商用利用するときは、ご自身の ElevenLabs プランの利用規約(商用利用の可否・クレジット表記など)を確認してください。
- ElevenLabs の Voice Library のボイスを使う場合、ボイス作成者の表記が必要なことがあります。その場合は `data/credits.json` の「こえ」の欄に追記してください(タイトル画面のクレジットとスタッフロールに自動で反映されます)。
