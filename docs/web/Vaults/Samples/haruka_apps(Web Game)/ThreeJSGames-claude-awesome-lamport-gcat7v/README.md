# ThreeJSGames

Three.js で作ったブラウザゲーム集 / Browser games made with three.js — by haruka_apps

| ゲーム | フォルダ | 内容 |
|---|---|---|
| そらキューブ ころりん / SKY CUBE KORORIN | [`sky-cube-kororin/`](sky-cube-kororin/) | かべを ぽちっと すると そこが「した」になる 3D じゅうりょく きりかえ アクション(約3〜5分・スマホ / PC 対応) |
| INKFALL | [`inkfall/`](inkfall/) | 重力 × インク陣取りバトル。全 6 面を重力フリップで駆け回って塗り合う。オンライン 2〜8 人(Wavedash SDK)/ CPU 戦 / ソロ練習・スコアチャレンジ(スマホ / PC 対応) |

各ゲームはフォルダごとに独立しています。Web サーバーでフォルダを開いて遊んでください(例: `cd sky-cube-kororin && python3 -m http.server 8000`)。
