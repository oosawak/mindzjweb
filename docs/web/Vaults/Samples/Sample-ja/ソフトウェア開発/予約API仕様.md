# 予約 API 仕様（サンプル）

## `POST /api/reservations`

備品の予約を作成します。

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `resource_id` | string | はい | 備品の識別子 |
| `starts_at` | ISO 8601 | はい | 利用開始時刻 |
| `ends_at` | ISO 8601 | はい | 利用終了時刻 |
| `purpose` | string | いいえ | 利用目的 |

## エラー

- `400`: 時刻の形式が不正、または終了時刻が開始時刻以前
- `409`: 指定した時間帯に既存予約がある
- `404`: 備品が見つからない

## 確認項目

- [ ] 同時に予約要求が来ても二重予約にならない
- [ ] 時刻は保存時に UTC へ正規化する
- [ ] キャンセル済み予約は空き状況に含めない
