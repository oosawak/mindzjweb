# ソフトウェア開発：備品予約サービス

> 小規模チーム向けの架空の Web サービスです。

## 目的

会議室や撮影機材の予約状況を共有し、二重予約を減らす。

## 構成メモ

```mermaid
flowchart LR
  User[利用者] --> Web[予約画面]
  Web --> API[予約 API]
  API --> DB[(予約データ)]
  API --> Notify[通知]
```

## 初期リリースの範囲

- 備品一覧と空き状況の表示
- 予約の作成、変更、キャンセル
- 予約者への確認通知
