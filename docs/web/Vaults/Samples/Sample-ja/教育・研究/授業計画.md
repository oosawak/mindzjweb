# 教育・研究：地域の水環境を調べる

> 架空の中学校の探究学習計画です。

## 学習目標

観察結果を記録し、根拠を示しながら水環境の変化を説明する。

## 3 回の活動

1. **問いを立てる:** どの場所で、何を比べるかを決める。
2. **観察・記録する:** 日時、天候、場所、観察内容を同じ書式で記録する。
3. **共有する:** 結果を表や図にまとめ、次に調べたいことを発表する。
