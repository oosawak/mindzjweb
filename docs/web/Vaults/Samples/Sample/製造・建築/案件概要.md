# 製造・建築：小型作業台の改良

> 架空の工房で使う作業台の改良案件です。

## 要求

- 使用者が一人で高さを調整できる
- 工具を置く棚を追加する
- 清掃しやすい構造にする

## 設計・確認項目

- [ ] 寸法図と部品表の版をそろえる
- [ ] 可動部に指を挟む隙間がないか確認する
- [ ] 試作品の耐荷重を記録する
- [ ] 変更内容を製作担当と検査担当に共有する
