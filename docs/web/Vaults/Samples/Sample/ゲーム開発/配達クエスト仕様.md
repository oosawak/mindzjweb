# 配達クエスト仕様：灯台への手紙

## 目的

プレイヤーが配達の基本操作を覚え、灯台守と港町の関係を知る。

## 開始条件

- 港の掲示板を調べる
- 配達依頼「灯台への手紙」を受注する

## 完了条件

1. 港で手紙を受け取る。
2. 船で北の灯台へ移動する。
3. 灯台守に手紙を渡す。
4. 港へ戻り、依頼完了の報告をする。

## 受け入れチェック

- [ ] 目的地が地図に表示される
- [ ] 手紙を受け取る前はクエストを完了できない
- [ ] 灯台守に話しかけると会話と演出が始まる
- [ ] 報酬と完了状態がセーブデータに記録される
