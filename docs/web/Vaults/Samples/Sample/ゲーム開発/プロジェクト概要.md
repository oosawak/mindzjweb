# ゲーム開発：星渡り郵便局

> 架空の小規模ゲーム開発プロジェクトです。

## 企画

プレイヤーが小さな飛行船で島々を巡り、手紙や荷物を届ける短編アドベンチャー。物語、クエスト、キャラクター設定、画像・音声・3D アセットをノートからたどれるように整理します。

## 今週の目標

- [ ] 配達クエストを1件、最初から最後まで遊べる状態にする
