# 映像・デザイン制作：地域イベント紹介動画

> 架空のイベントを紹介する 60 秒動画の制作メモです。

## ねらい

イベントの雰囲気と開催情報を、初めて見る人に短時間で伝える。

## 制作条件

- 尺：60 秒
- 形式：16:9、字幕あり
- 公開先：イベント告知ページと SNS
- トーン：親しみやすく、落ち着いた色調
